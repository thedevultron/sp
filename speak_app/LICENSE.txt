FREE & BYOK NOTICE:
SPEAK is free to use out of the box (free tier via embedded fallback). Users may
optionally add their own Gemini API key (BYOK) in Settings > Setup for unlimited
usage. When a user key is present, it is used exclusively; the embedded fallback
is not used. No user keys are displayed in UI or logs.

PRIVACY & API USAGE NOTICE:
All API requests are transmitted directly from your local machine to Google GenAI.
No speech data, screen frames, or API credentials are sent to or stored on any
third-party intermediary servers. Local credentials are encrypted via Windows
Credential Vault (keyring). Embedded fallback key is obfuscated in binary and
never logged or shown.
